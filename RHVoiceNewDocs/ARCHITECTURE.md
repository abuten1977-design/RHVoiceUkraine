# RHVoice Ukrainian — Architecture

Documented commit: `f9c1c6c0` on branch `ci/macos-gates-2026-04-26`,
repo `abuten1977-design/RHVoiceUkraine`.

## 1. What the product is

Four Ukrainian voices (Anatol, Marianna, Natalia, Volodymyr) usable by Apple
VoiceOver and other text‑to‑speech clients on **iOS 16+** and **macOS 13+**,
delivered as an `AVSpeechSynthesisProvider` audio‑unit extension plus a small
host app for per‑voice configuration. The synthesis engine is the open‑source
**RHVoice** C/C++ engine, compiled as part of the build (not a prebuilt dylib).

Primary user is a blind developer; VoiceOver is the main client. This drives two
hard requirements: (a) speech rate must scale correctly across the VoiceOver
rotor range, and (b) the host‑app UI must be fully accessible and localized.

## 2. Platforms and Xcode targets

The Xcode project is generated by **XcodeGen** from `UkrainianVoicesApp/project.yml`.
Targets:

| Target | Type | Platform | Role |
|---|---|---|---|
| `RHVoiceKit` | framework | iOS | Engine wrapper for iOS; depends on SwiftPM `RHVoiceCore` (product `RHVoiceBridge`) |
| `RHVoiceKitMac` | framework | macOS | Engine wrapper for macOS; **compiles RHVoice C sources in‑target** |
| `UkrainianVoices` | application | iOS | iOS host/config app |
| `UkrainianVoicesExtension` | app‑extension | iOS | iOS speech provider extension |
| `UkrainianVoicesMac` | application | macOS | macOS host/config app |
| `UkrainianVoicesExtensionMac` | app‑extension | macOS | macOS speech provider extension |

**Key asymmetry (important for analysis):**

- **macOS** compiles the RHVoice C/C++ sources directly inside `RHVoiceKitMac`
  (sources include `../RHVoice/src/core`, etc.), with preprocessor defines in
  `project.yml` (`ENABLE_SONIC=1`, `MAX_RATE=20`, `RHVOICE_MAX_MAX_RATE=20`).
- **iOS** does not compile C in‑target; iOS targets depend on the SwiftPM
  package `RHVoiceCore` (`RHVoiceCore/Package.swift`, product `RHVoiceBridge`)
  which compiles the same C/C++ with its own `cSettings` defines
  (`MAX_RATE=20`, `RHVOICE_MAX_MAX_RATE=20`, `ENABLE_SONIC=1`, `sonic.c`).

So a given engine knob may need to be set in **two places** (project.yml for
macOS, Package.swift for iOS). This was the source of more than one bug.

## 3. Layered structure

```
VoiceOver / TTS client
        │  (SSML request: text + prosody rate/volume)
        ▼
AVSpeechSynthesisProvider extension  (Swift)
  UkrainianVoicesApp/Extension/Provider/
    AudioUnitFactory.swift            – AU factory/registration
    UkrainianSpeechSynthesizer.swift  – core: parse SSML, read settings, map params, drive engine
        │
        ▼
Obj‑C++ engine bridge
  iOS:  RHVoiceCore/Bridge/Sources/RHVoiceEngine.mm (+ RHVoiceEngine+Parameters.mm)
  mac:  RHVoiceKit/Sources/RHVoiceEngine.mm        (+ RHVoiceEngine+Parameters.mm)
        │  (config_path = bundled RHVoiceData; rate/volume/pitch; text)
        ▼
RHVoice C/C++ engine        RHVoice/src/core/
    params.cpp        – rate/pitch/volume settings, MAX_MAX_RATE clamp
    language.cpp      – tokenization, phrasing, bilingual/foreign words, pauses
    ukrainian.cpp     – Ukrainian g2p; untranslit fallback for Latin
    hts_label.cpp     – speech‑param calc (rate clamp point)
    + Sonic (RHVoice/external/libs/sonic/sonic.c) – time‑stretch for fast speech
        │
        ▼
PCM audio → returned to VoiceOver
```

Settings flow (separate channel, not through SSML):

```
Host app UI (ContentView.swift)
   → RHVoiceSharedSettingsStore.saveSnapshot()
   → App Group container  "group.rhvoice.UkrainianVoices.shared"
   → RHVoiceSharedSettingsStore.loadSnapshot() inside the extension
```

## 4. Modules / classes / functions

### 4.1 Extension (Swift) — `UkrainianVoicesApp/Extension/Provider/`

- **`AudioUnitFactory.swift`** — `AVSpeechSynthesisProviderAudioUnit` factory;
  registers voices and creates the synthesizer AU.
- **`UkrainianSpeechSynthesizer.swift`** — the heart. Class
  `UkrainianSpeechSynthesizer: AVSpeechSynthesisProviderAudioUnit`.
  Key members:
  - `synthesizeSpeechRequest(_:)` — called by the system with an
    `AVSpeechSynthesisProviderRequest` (SSML + voice id). Pipeline:
    1. `extractSSMLRatePercent(from:)` — pull `prosody rate="X%"` from SSML.
    2. `extractSSMLVolume(from:)` — pull `volume="±dB"`.
    3. `RHVoiceSharedSettingsStore.loadSnapshot()` →
       `snapshot.effectiveSettings(for: voiceId)` — per‑voice settings.
    4. `mapSSMLRatePercentToEngineMultiplier(_:)` — the **speed curve**
       (platform‑specific, see PARAMS_AND_BUILD.md).
    5. `clampAccelerator(_:)` — clamps app multiplier to `1.0…4.0`.
    6. `finalRate = mappedRate * accelerator`.
    7. `effectiveVolume = ssmlVolume` and `effectivePitch = 1.0`
       (volume/pitch are deliberately pass‑through so VoiceOver controls them).
    8. `applyTextBreaks(to:sentencePauseMs:wordGapMs:)` — SSML‑safe insertion
       of `<break>` for sentence pause and word gap (see §4.4).
    9. Calls the Obj‑C++ engine bridge `synthesize(text, voice, rate, volume, pitch)`.
  - `os_log` category `params` line tagged `PARAMS …` — the on‑device
    measurement/telemetry used to diagnose rate behavior.
  - `rhLog(_:)` → C `RHVoiceDebugLogString` → debug log file in the App Group
    container.

### 4.2 Shared model — `UkrainianVoicesApp/Shared/RHVoiceSharedSettings.swift`

- `enum RHVoiceSharedSettings` — constants. App Group id
  `group.rhvoice.UkrainianVoices.shared`; snapshot file
  `SharedSettingsSnapshot.json`; voice catalog (4 voices, ids like
  `com.rhvoice.UkrainianVoices.anatol`).
- `struct RHVoiceSpeechSettings` — `rate, volume, speedMultiplier,
  sentencePause, wordGap, pitch`. Custom `init(from:)` decodes missing fields
  with defaults (backward compatible: `pitch`, `wordGap` default when absent).
- `struct RHVoicePerVoiceSettings` — `useCustomSettings: Bool` + settings.
  `inherited(from:)` now sets `useCustomSettings = true` (so the extension
  always applies the per‑voice values; see CHALLENGES §App Group).
- `struct RHVoiceSharedSettingsSnapshot` — versioned snapshot
  (schemaVersion, revision, voiceCatalog, enabled ids, selected id,
  generalSettings, perVoiceSettings). `effectiveSettings(for:)` returns the
  per‑voice settings when `useCustomSettings`, else general.
- `enum RHVoiceSharedSettingsStore` — `saveSnapshot` / `loadSnapshot`.
  Writes a JSON file in the App Group container **and** mirrors values into
  `UserDefaults(suiteName: appGroupID)` (legacy fallback). `loadSnapshot`
  prefers the file, falls back to defaults.
- **`RHVoiceSynthesisRuntime.swift`** — shared synthesis helpers used by app/ext.

### 4.3 Host app — `UkrainianVoicesApp/App/`

- `UkrainianVoicesApp.swift` — app entry.
- `ContentView.swift` — SwiftUI UI + `ContentViewModel`. After simplification:
  a list of voices → per‑voice screen with **enable toggle**, **Preview**
  button ("Це тест голосу <name>"), and exactly three sliders:
  **Прискорювач (1…4)**, **Пауза між реченнями (0…2000 ms)**,
  **Проміжок між словами (0…300 ms)**. Speech‑rate/volume/pitch sliders were
  removed (VoiceOver owns those). `sliderRow(...)` hides the visual label from
  VoiceOver (`.accessibilityHidden(true)`) so the slider is a single
  accessibility element (fixes a duplicate‑announcement bug).
  All persistence goes through `RHVoiceSharedSettingsStore` with
  `useCustomSettings = true`.
- `LogCollector.swift` — in‑app log buffer (app‑side only; can email logs).
- `RHVoiceSelfTestRunner.swift` — diagnostics (macOS).

### 4.4 SSML‑safe break insertion (in `UkrainianSpeechSynthesizer.swift`)

`applyTextBreaks(to:sentencePauseMs:wordGapMs:)` scans the SSML character by
character, tracking whether it is inside a `<...>` tag. Tags/attributes are
copied verbatim; `<break>` is inserted **only inside text segments**:

- after `. , ! ?` for sentence pause, **unless** it is a decimal separator
  (digit before and after) — `isDecimalSeparator`;
- between words for word gap (word char, then whitespace, then a word) when
  `wordGap > 0`.

This replaced an earlier naïve regex that matched dots inside attributes/numbers
and corrupted SSML (see CHALLENGES).

### 4.5 Engine bridge (Obj‑C++)

`RHVoiceEngine.mm` (two copies: `RHVoiceKit/Sources` for macOS in‑target,
`RHVoiceCore/Bridge/Sources` for the iOS SwiftPM package) plus
`RHVoiceEngine+Parameters.mm`. Sets `params.config_path` to the bundled
`RHVoiceData` directory (so `RHVoice.conf` is read), passes text + rate/volume/
pitch into the RHVoice C API, returns PCM.

### 4.6 RHVoice C/C++ engine — `RHVoice/src/core/`

- `params.cpp` — `MAX_MAX_RATE` (= `RHVOICE_MAX_MAX_RATE` macro, default 5);
  `max_rate("max_rate", MAX_RATE, 1, MAX_MAX_RATE)`. The absolute speed ceiling.
- `language.cpp` — tokenization, phrasing, `insert_pauses`, and bilingual /
  foreign‑word handling: `try_as_foreign_subtoken`, `get_second_language`
  (uses the per‑language `bilingual` property + a `foreign_phone_mapping_fst`).
- `ukrainian.cpp` — Ukrainian grapheme‑to‑phoneme; `decode_as_word` uses
  `untranslit_fst` (the Latin→Cyrillic transliteration fallback).
- `hts_label.cpp` — `calculate_speech_param`; rate clamp point.
- Sonic (`RHVoice/external/libs/sonic/sonic.c`) — time‑stretch enabling
  fast‑but‑intelligible speech (analogous to NVDA rate boost).

## 5. Bundled data — `UkrainianVoicesApp/Extension/Resources/RHVoiceData/`

Single shared data tree copied into **all** app/extension bundles (iOS and
macOS) by `project.yml` post‑build scripts (one `DATA_SRC`, four destinations):

- `languages/Ukrainian/` — Ukrainian module incl. `untranslit.fst`,
  `english_phone_mapping.fst`. `language.info` now contains `bilingual=English`.
- `languages/English/` — full English module (cmulex, vocab, tok, …) so Latin
  words are spoken as English (mapped onto the Ukrainian voice via the phone
  mapping) instead of being transliterated.
- `voices/{anatol,marianna,natalia,volodymyr}/` — the voice data.
- `RHVoice.conf` — `languages.ukrainian.default_rate=1`,
  `languages.ukrainian.max_rate=20`, `languages.ukrainian.min_sonic_rate=1`.

Because the data tree is shared, a data/config change applies to both platforms
automatically.

## 6. Settings sync (App Group)

App and extension share `group.rhvoice.UkrainianVoices.shared`. The host app
writes a snapshot (JSON file + UserDefaults mirror); the extension reads it on
each request. VoiceOver still owns speech rate/volume/pitch via SSML — the app
settings only carry the things VoiceOver cannot express (Accelerator, Sentence
pause, Word gap) plus per‑voice enable/selection. App Group entitlement is
present and provisioned for both iOS app and iOS extension App IDs.

See PARAMS_AND_BUILD.md for the exact parameter math and the build/CI pipeline,
and CHALLENGES_AND_SOLUTIONS.md for the failure modes around all of the above.
