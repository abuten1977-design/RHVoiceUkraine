# RHVoice Build Log - 19.09.2025

## Overall Goal
Compile the RHVoice speech synthesis engine with Ukrainian voices on a macOS machine.

## Key Knowledge
- The user's primary goal is to build RHVoice with Ukrainian voices (`anatol`, `natalia`, etc.).
- The build environment is a modern macOS machine with Homebrew installed at `/opt/homebrew`.
- The RHVoice build system is old and has numerous compatibility issues with macOS, requiring multiple patches to the `CMakeLists.txt` files.
- Standard CMake variables like `CMAKE_PREFIX_PATH` and `CMAKE_LINKER_FLAGS` are not being respected by the build scripts.
- A custom linker workaround script (`clangLinkerWorkaround.sh`) was found to be broken and was preventing executables from being created.
