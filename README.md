# RHVoice Ukrainian — VoiceOver voices for iOS & macOS

[![Build RHVoice Ukraine](https://github.com/abuten1977-design/RHVoiceUkraine/actions/workflows/build.yml/badge.svg)](https://github.com/abuten1977-design/RHVoiceUkraine/actions/workflows/build.yml)

Four Ukrainian text‑to‑speech voices — **Anatol, Marianna, Natalia, Volodymyr** — packaged as a system speech‑synthesis provider for **VoiceOver** on **iOS 16+** and **macOS 13+**. Built on the open‑source [RHVoice](https://github.com/RHVoice/RHVoice) engine.

## What ships

The product is one bundle made of two parts:

- **App** — settings UI (speed accelerator, pauses), a built‑in **Preview** button, and diagnostics. The app itself never speaks through VoiceOver.
- **Extension** — an `AVSpeechSynthesisProviderAudioUnit` that VoiceOver invokes to speak. **This is the actual voice.**

They share data through the App Group `group.rhvoice.UkrainianVoices.shared`.

## How it works (short)

```
VoiceOver (SSML) → Extension (UkrainianSpeechSynthesizer)
  → split into sentence fragments → ObjC++ bridge (RHVoiceEngine)
  → RHVoice C++ engine → PCM audio → render callback → VoiceOver
```

The RHVoice C/C++ engine is **compiled from source** (iOS via the `RHVoiceCore` SwiftPM package → product `RHVoiceBridge`; macOS in‑target via `RHVoiceKitMac`). Linking prebuilt `.a`/`.dylib` is considered a regression.

VoiceOver controls voice/rate/volume/pitch via SSML; the app only stores what VoiceOver cannot: the speed accelerator, sentence pause and word gap.

## Building

The project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen), not committed `.xcodeproj` files:

```sh
cd UkrainianVoicesApp
xcodegen generate
# macOS (local, unsigned):
xcodebuild -project UkrainianVoices.xcodeproj -scheme UkrainianVoicesMac \
  -configuration Debug -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO build
```

Signed iOS builds and TestFlight delivery run through GitHub Actions (`build.yml`, manual `workflow_dispatch`); the build number equals the workflow run number.
