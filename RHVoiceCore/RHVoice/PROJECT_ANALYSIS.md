# RHVoice - Основной проект синтезатора речи

## 📋 ОПИСАНИЕ
Базовый проект RHVoice с GitHub - многоплатформенный синтезатор речи с открытым исходным кодом.

## 🎯 НАЗНАЧЕНИЕ
- Основной источник исходного кода RHVoice
- Содержит все языковые данные и голоса
- Поддерживает множество платформ (iOS, macOS, Android, Windows, Linux)

## 📁 СТРУКТУРА ПРОЕКТА

### Основные файлы:
- `CMakeLists.txt` - Конфигурация сборки CMake (модифицированная)
- `SConstruct` - Альтернативная система сборки SCons
- `README.md` - Официальная документация проекта
- `LICENSE.md` - Лицензия GPL v3

### Исходный код (`src/`):
- `lib/` - Основная библиотека RHVoice
- `core/` - Ядро синтезатора
- `audio/` - Аудио подсистема
- `include/` - Заголовочные файлы API
- `hts_engine/` - HTS движок синтеза
- `third-party/` - Внешние зависимости

### Данные (`data/`):
- `languages/` - Языковые модели (19+ языков включая украинский)
- `voices/` - Голосовые модели

### Build папки (результаты сборки):
- `build_ios_static/` - Статические библиотеки для iOS
- `build_macos_x86_64/` - Динамические библиотеки для macOS Intel
- `build_ios_simulator/` - Библиотеки для iOS симулятора
- `install_x86_64/` - Установленные файлы для macOS

## ✅ УСПЕШНЫЕ СБОРКИ
1. **macOS x86_64**: `libRHVoice.dylib` - работает
2. **iOS Static**: Статические библиотеки собраны
