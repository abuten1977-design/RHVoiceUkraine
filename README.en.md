# RHVoice Ukrainian

**Ukrainian text-to-speech voices for VoiceOver on iPhone, iPad and Mac.**

RHVoice Ukrainian is a system extension that adds four high-quality Ukrainian voices
(**Anatol**, **Marianna**, **Natalia**, **Volodymyr**) directly to Apple's VoiceOver screen
reader. The voices appear in the VoiceOver rotor alongside the built-in system voices and run
**entirely on the device** — the text you read is never sent anywhere.

The project is built for blind and low-vision Ukrainian-speaking users, for whom a high-quality
Ukrainian voice is a matter of working independently with their device every day.

> 🇺🇦 Українська версія: [README.uk.md](README.uk.md)

## Features

- **4 voices** of different genders: Anatol, Volodymyr (male), Marianna, Natalia (female).
- **VoiceOver integration** through Apple's official `AVSpeechSynthesisProviderAudioUnit`
  (iOS 16+, macOS 13+). The voices are treated as first-class system voices.
- **Synthesis runs entirely on the device.** The engine and the Ukrainian language data are bundled in the app; the text being spoken is never sent anywhere. The network is used only when you choose to download an additional voice for another language.
- **Parameter control** (speed, volume, pitch) via standard VoiceOver controls, plus in-app
  per-voice tuning (speed accelerator, sentence pause, word gap).
- **Personal pronunciation dictionary** — users can correct the stress of individual words.
- **Correct handling** of apostrophes, numbers and decimal fractions, and mixed
  Ukrainian/English text.

## How it works (short)

Text from VoiceOver enters the synthesizer extension, is prepared (sentence splitting,
apostrophe and number normalization) and synthesized to audio by the RHVoice engine:

```
VoiceOver (system)
   │  text + voice + parameters (SSML)
   ▼
UkrainianSpeechSynthesizer (Swift, AVSpeechSynthesisProviderAudioUnit)
   │
   ├─ RHVoicePipelineSplitter — sentence splitting, stripping of unknown SSML tags
   ├─ apostrophe & number normalization
   ▼
RHVoiceEngine (Objective-C++ bridge) → RHVoice 1.16.4 engine (C/C++, statically compiled)
   │  synchronous per-fragment synthesis → 24 kHz PCM
   ▼
Audio to VoiceOver
```

A detailed technical description is in [docs/ARCHITECTURE.en.md](docs/ARCHITECTURE.en.md).

| Folder | Purpose |
|--------|---------|
| `UkrainianVoicesApp/` | Main project (app + extension), generated by XcodeGen from `project.yml` |

## Building from source

Requires **macOS**, **Xcode** and **XcodeGen**.

```bash
cd UkrainianVoicesApp
xcodegen generate          # generate the .xcodeproj from project.yml
open UkrainianVoices.xcodeproj
```

The signed and notarized macOS build is automated via GitHub Actions; the iOS build for
TestFlight is produced by a local script on the Mac.
