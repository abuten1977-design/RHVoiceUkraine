## Як правити клас B

### 1. Простий текст без вставок

```swift
// було
let title = "Мій словник"
// стало
let title = NSLocalizedString("Мій словник", comment: "")
```

### 2. Текст зі вставкою `\(...)`

Ключ = той самий текст, де КОЖНА вставка `\(...)` замінена на `%@`.
Значення передавати рядком (`String(...)`, `.description`, вже готовий `String`).

```swift
// було
setStatus("Не вдалося підготувати файл словника: \(error.localizedDescription)")
// стало
setStatus(String(format: NSLocalizedString("Не вдалося підготувати файл словника: %@", comment: ""),
                 error.localizedDescription))
```

Якщо вставок кілька — порядок `%@` такий самий, як у джерелі. У перекладі дозволено
міняти порядок через `%1$@`, `%2$@`.

Уже наявні printf-формати (`"%.1f МБ"`) залишати як є, лише загорнути в `NSLocalizedString`.

### 3. Текст, який ПОРІВНЮЮТЬ або шукають

**Найнебезпечніше місце.** Якщо рядок десь порівнюється, сортується, служить ключем
словника, ключем UserDefaults або йде у двигун — **значення НЕ чіпати**.
Перекладати тільки в МІСЦІ ПОКАЗУ:

```swift
// дані лишаються українськими (це тотожність, а не текст для очей)
Text(LocalizedStringKey(voice.displayName))
```

Це стосується щонайменше: назв голосів, назв мов (`preferredLanguageOrder`),
пресетів прискорювача, назв сили паузи. Перед правкою — переконатися grep-ом,
чи цей рядок десь порівнюється.
