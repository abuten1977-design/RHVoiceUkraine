# Збірки та вихідний код / Builds and Corresponding Source

Кожна збірка, роздана через TestFlight, позначена тегом у цьому репозиторії.
Тег `build-N` вказує на коміт, з якого зібрано збірку номер N.

**Як отримати вихідний код конкретної збірки.** Номер збірки видно в застосунку:
екран «Ліцензії» → розділ «Правова інформація». Далі:

```sh
git clone https://github.com/abuten1977-design/RHVoiceUkraine.git
cd RHVoiceUkraine
git checkout build-251     # замініть на потрібний номер
```

**Як зібрати.** Потрібні macOS з Xcode і XcodeGen:

```sh
cd UkrainianVoicesApp
xcodegen generate
xcodebuild -project UkrainianVoices.xcodeproj -scheme UkrainianVoices \
           -destination 'generic/platform=iOS' build
```

Для версії під macOS використовується схема `UkrainianVoicesMac`.

## Правило на майбутнє

Кожна нова збірка, яка йде в TestFlight або App Store, спершу комітиться, потім
позначається тегом `build-N`, і лише тоді збирається. Збірка з незбережених змін
не роздається — інакше неможливо видати вихідний код саме тієї версії, як того
вимагає GPL-3.
