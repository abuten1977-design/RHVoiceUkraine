# RHVoice Ukrainian

**Українські голоси синтезу мовлення для VoiceOver на iPhone, iPad та Mac.**

RHVoice Ukrainian — це системне розширення, яке додає чотири якісні україномовні голоси
(**Anatol**, **Marianna**, **Natalia**, **Volodymyr**) безпосередньо в екранний доступ
Apple VoiceOver. Голоси з'являються в роторі VoiceOver поряд із вбудованими системними
голосами і працюють **повністю офлайн** — без інтернету, без передавання тексту кудись назовні.

Проєкт створено для незрячих та слабозорих україномовних користувачів, для яких якісний
синтез українською — це питання щоденної самостійної роботи з пристроєм.

> 🇬🇧 English version: [README.en.md](README.en.md)

---

## Можливості

- **4 голоси** різної статі: Anatol, Volodymyr (чоловічі), Marianna, Natalia (жіночі).
- **Інтеграція з VoiceOver** через офіційний клас Apple `AVSpeechSynthesisProviderAudioUnit`
  (iOS 16+, macOS 13+). Голоси рівноцінні системним.
- **Повністю офлайн.** Рушій і мовні дані вбудовані в застосунок; мережа не використовується.
- **Керування параметрами** мовлення (швидкість, гучність, висота тону) стандартними
  засобами VoiceOver, а також додатковими регуляторами в застосунку (прискорювач швидкості,
  пауза між реченнями, проміжок між словами — окремо для кожного голосу).
- **Персональний словник наголосів** — користувач може виправити вимову окремих слів.
- **Коректна обробка** апострофів, чисел і десяткових дробів, змішаного українсько-англійського
  тексту.

## Як це працює (коротко)

Текст від VoiceOver надходить у розширення-синтезатор, проходить підготовку (розбиття по
реченнях, нормалізація апострофів і чисел) і синтезується рушієм RHVoice у звук:

```
VoiceOver (система)
   │  текст + голос + параметри (SSML)
   ▼
UkrainianSpeechSynthesizer (Swift, AVSpeechSynthesisProviderAudioUnit)
   │
   ├─ RHVoicePipelineSplitter — розбиття по реченнях, вирізання невідомих SSML-тегів
   ├─ нормалізація апострофів і чисел
   ▼
RHVoiceEngine (Objective-C++ міст) → рушій RHVoice 1.16.4 (C/C++, статична компіляція)
   │  синхронний синтез фрагмента → PCM 24 кГц
   ▼
Аудіо у VoiceOver
```

Детальний технічний опис — у [docs/ARCHITECTURE.uk.md](docs/ARCHITECTURE.uk.md).

## Структура репозиторію

| Тека | Призначення |
|------|-------------|
| `UkrainianVoicesApp/` | Основний проєкт (застосунок + розширення), генерується XcodeGen з `project.yml` |

| `RHVoiceKit/` | Міст до рушія RHVoice для macOS |
| `RHVoice/` | Вихідний код рушія RHVoice (C/C++), без модифікацій |
| `.github/workflows/` | CI/CD: підписана та нотаризована збірка macOS |

## Збірка з вихідного коду

Потрібні **macOS**, **Xcode** і **XcodeGen**.

```bash
cd UkrainianVoicesApp
xcodegen generate          # згенерувати .xcodeproj з project.yml
open UkrainianVoices.xcodeproj
```

Підписана та нотаризована збірка macOS автоматизована через GitHub Actions; збірка iOS
для TestFlight виконується локальним скриптом на Mac.
