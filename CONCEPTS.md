## Что такое xcodeproj

Файл с расширением .xcodeproj — это папка которая описывает проект для Xcode.
Внутри написано: какие файлы компилировать, какие настройки использовать, как подписывать.

Аналогия: как оглавление книги. Сама книга — это твои Swift файлы.
Xcodeproj говорит Xcode где они лежат и что с ними делать.

У поляков: ~/Projects/rhvoice-ee/rhvoice-ee.xcodeproj
У нас (создал Copilot): ~/Projects/RHVoiceUkraine/UkrainianVoicesApp/UkrainianVoicesMac.xcodeproj

## Что такое Bundle ID

Уникальное имя приложения для Apple. Выглядит как com.компания.приложение.

Примеры:
- com.apple.safari — это Safari
- com.andriybutenko.RHVoiceUA — это наше приложение

Зачем: Apple по Bundle ID отличает одно приложение от другого.
Два приложения с одинаковым Bundle ID не могут существовать на одном устройстве.

## Чем отличается структура поляков от нашей

Проект поляков:
- Язык: Swift + Objective-C++ (смешанный)
- C++ движок: компилируется прямо внутри проекта через Swift Package (папка Core)
- Xcode проект: rhvoice-ee.xcodeproj — всё в одном месте
- Голоса: польский Natan + другие

Наш проект:
- Язык: чистый Swift (цель)
- C++ движок: те же библиотеки поляков, подключены через symlink
- Xcode проект: создал Copilot, но не до конца настроен
- Голоса: украинские Anatol, Marianna, Natalia, Volodymyr

Главное отличие:
У поляков Objective-C++ — это мост между Swift и C++.
Мы хотим обойтись без него, используя готовый Swift Package от поляков (import RHVoice).

## Почему у нас не компилируется

Swift Package Manager (swift build) не умеет компилировать
смешанный C++ и Swift код в одном target.

Xcode умеет — он делает это правильно.
Поэтому нужно собирать через xcodebuild, а не swift build.

---

## Что такое Extension (.appex)

Маленькая программа которая живёт внутри основного приложения.
Расширение .appex — это Speech Synthesis Provider.

Когда устанавливаешь приложение:
1. Система находит .appex внутри него
2. Регистрирует голоса в системе
3. Голоса появляются в Настройки — Универсальный доступ — VoiceOver — Речь — Голос

---

## Что такое App Group

Общая папка для обмена данными между приложением и Extension.
Нужна потому что Extension — отдельный процесс, не может читать данные приложения напрямую.

Настройки скорости и паузы хранятся в App Group чтобы
и приложение и Extension видели одни и те же настройки.
