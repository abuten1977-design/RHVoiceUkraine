# RHVoice Build Log - 2025-09-19

This file summarizes the steps taken to successfully configure and start compiling RHVoice on macOS.

## 1. Environment Setup
- Cloned the repository: `git clone https://github.com/RHVoice/RHVoice`
- Initialized submodules: `git -C RHVoice submodule update --init --recursive`
- Installed dependencies via Homebrew: `brew install cmake dbus glibmm tclap libao portaudio pulseaudio utf8cpp pkg-config boost`

## 2. Source Code Modifications

### A. Cleaned Unnecessary Voices
- Removed all voice submodules except for the Ukrainian ones (`anatol`, `marianna`, `natalia`, `volodymyr`) from `RHVoice/data/voices/`.

### B. Patched CMakeLists.txt
1.  **Forced bundled `utf8` library:**
    - **File:** `RHVoice/src/CMakeLists.txt`
    - **Change:** Replaced the `find_package(utf8cpp)` block with a direct path assignment: `set(UTF8_INCLUDE_DIR "${CMAKE_CURRENT_SOURCE_DIR}/src/third-party/utf8")`

2.  **Forced C++14 Standard:**
    - **File:** `RHVoice/CMakeLists.txt`
    - **Change:** Replaced the conditional C++ standard block with `set(CMAKE_CXX_STANDARD 14)`.

3.  **Added Boost Include Directory:**
    - **File:** `RHVoice/CMakeLists.txt`
    - **Change:** Added `include_directories("/opt/homebrew/opt/boost/include")` after the `project()` declaration.

## 3. Build Commands

- **CMake Configuration:**
  `cmake -S RHVoice -B RHVoice/build -DCMAKE_POLICY_VERSION_MINIMUM=3.5 -DBUILD_SPEECHDISPATCHER_MODULE=OFF -DBUILD_SERVICE=OFF`

- **Compilation:**
  `make -C RHVoice/build`
