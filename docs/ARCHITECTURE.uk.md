# Архітектура RHVoice Ukrainian

Цей документ описує архітектуру застосунку так, як вона реалізована в коді.

> 🇬🇧 English: [ARCHITECTURE.en.md](ARCHITECTURE.en.md)

## Загальний огляд

RHVoice Ukrainian — це **постачальник системних голосів** для VoiceOver, а не самостійний
«читач». Apple дозволяє стороннім синтезаторам інтегруватися у VoiceOver через клас
`AVSpeechSynthesisProviderAudioUnit` (iOS 16+, macOS 13+). Наше розширення реалізує цей клас,
і система звертається до нього, коли треба озвучити текст обраним українським голосом.

Застосунок складається з двох частин:

- **Host-застосунок** (`UkrainianVoices` / `UkrainianVoicesMac`) — UI на SwiftUI: вмикання
  голосів, регулятори, персональний словник, прослуховування прикладу.
- **Розширення-синтезатор** (`UkrainianVoicesExtension` / `…Mac`) — окремий системний процес,
  що приймає запити VoiceOver і повертає аудіо.

Дві частини обмінюються налаштуваннями через **App Group**
(`group.rhvoice.UkrainianVoices.shared`).

## Збірка (XcodeGen)

Єдине джерело правди про збірку — `UkrainianVoicesApp/project.yml` (маніфест XcodeGen).
Сам `.xcodeproj` у git не зберігається, а генерується командою `xcodegen generate`.

Основні таргети:

| Таргет | Тип | Платформа | Роль |
|--------|-----|-----------|------|
| `UkrainianVoices` | застосунок | iOS | Host-застосунок, UI налаштувань |
| `UkrainianVoicesExtension` | розширення | iOS | Синтезатор (AVSpeechSynthesisProviderAudioUnit) |
| `UkrainianVoicesMac` | застосунок | macOS | Host-застосунок macOS |
| `UkrainianVoicesExtensionMac` | розширення | macOS | Синтезатор macOS |
| `RHVoiceKit` / `RHVoiceKitMac` | фреймворк | iOS / macOS | Обгортка рушія; на macOS компілює C/C++ рушій у таргеті |

Рушій RHVoice **компілюється статично** у бандл (вимога Apple: жодних динамічних `.dylib`).

## Конвеєр синтезу (текст → звук)

Шлях від запиту VoiceOver до аудіо:

1. **Прийом запиту.** `UkrainianSpeechSynthesizer`
   (`UkrainianVoicesApp/Extension/Provider/UkrainianSpeechSynthesizer.swift`) отримує від
   VoiceOver текст у форматі SSML разом із голосом і параметрами (швидкість, гучність, висота).

2. **Розбір параметрів.** З SSML вичитуються `rate`, `volume`, `pitch`. Швидкість мапиться у
   множник рушія за **платформозалежною кривою** (iOS і macOS мають різні стелі швидкості),
   далі домножується на «прискорювач» із налаштувань користувача.

3. **Підготовка тексту:**
   - `RHVoicePipelineSplitter` (`UkrainianVoicesApp/Shared/RHVoicePipelineSplitter.swift`)
     розбиває текст **по реченнях**, вирізає невідомі рушієві SSML-теги (наприклад `<say-as>`,
     `<voice>`), зберігаючи сам текст. Це дає миттєвий старт озвучення довгого тексту.
   - **Нормалізація апострофів** зводить різні варіанти апострофа до форми, яку рушій вимовляє
     коректно.
   - **Нормалізація чисел і дробів** розгортає числа в українські слова там, де це потрібно.
   - За потреби вставляються паузи між реченнями та проміжки між словами.

4. **Синтез.** `RHVoiceEngine` (Objective-C++ міст, `RHVoiceEngine.mm`) викликає рушій RHVoice
   **синхронно** (`RHVoice_speak`) для кожного фрагмента. Рушій через callback віддає шматки
   PCM, які збираються в буфер і конвертуються у Float32.

5. **Віддача аудіо.** Метод `performRender` працює за принципом **pull** (eSpeak-style): система
   періодично запитує наступні аудіо-фрейми, а розширення віддає вже синтезовані дані з плоского
   буфера. Частота дискретизації — **24 кГц**, моно.

> **Важливо:** реалізація **синхронна**, не потокова. Рушій спочатку синтезує фрагмент повністю,
> і лише потім аудіо віддається системі. Розбиття по реченнях зменшує відчутну затримку старту.

## Рушій RHVoice

- **Версія: 1.16.4**, вихідний код у теці `RHVoice/`, без модифікацій логіки.
- Мовні дані (HTS-моделі голосів, український і англійський модулі, словники) вбудовані в
  ресурси розширення (`Extension/Resources/RHVoiceData/`).
- Англійський модуль потрібен для коректної вимови латинських слів у змішаному тексті.
- Для розтягування швидкого мовлення використовується бібліотека `sonic`.

**Інваріант швидкості:** максимальна досяжна швидкість (крива × прискорювач) має лишатися нижче
стелі рушія (`max_rate`). Будь-яка зміна кривої чи стелі прискорювача потребує повторної
перевірки цього інваріанта, інакше повертається «стеля швидкості».

## Налаштування й дані

- **Снапшот налаштувань** — JSON-файл `SharedSettingsSnapshot.json` у контейнері App Group
  (`RHVoiceSharedSettings.swift`). Містить каталог голосів, увімкнені голоси, загальні та
  по-голосні параметри. Є резервний шлях через `UserDefaults` для сумісності зі старими збірками.
- **Персональний словник** (`PersonalUserDictionary.swift`) — користувацькі виправлення наголосів,
  зберігаються в App Group і застосовуються рушієм. Про зміни розширення дізнається через
  крос-процесну Darwin-нотифікацію.

## Спільний код iOS / macOS

Тека `UkrainianVoicesApp/Shared/` спільна для обох платформ (сплітер, налаштування, словник).
Objective-C++ мости (`RHVoiceCore` для iOS, `RHVoiceKit` для macOS) функціонально ідентичні.
Платформні відмінності позначені директивами `#if os(macOS)` / `#if os(iOS)` — головно у стелі
швидкості та шляхах контейнера.

## CI/CD

`.github/workflows/`:

- **iOS → TestFlight** — генерація проєкту XcodeGen, збірка, автопідписання ключем App Store
  Connect, завантаження в TestFlight.
- **macOS signed** — збірка, підписання сертифікатом Developer ID, нотаризація Apple.

Окрім CI, є локальні скрипти збірки на Mac (основний робочий шлях; GitHub Actions — запасний).
